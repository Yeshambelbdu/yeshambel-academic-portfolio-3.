# Yeshambel Asmare Mengist — Academic Portfolio

A responsive static academic website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — all page sections and content
- `styles.css` — responsive layout, colors, typography, and component styling
- `script.js` — mobile navigation, current year, and active section navigation
- `Yeshambel_Asmare_Academic_CV.docx` — downloadable academic CV in Microsoft Word format
- `yeshambel-professional-photo.jpg` — homepage professional photograph

## Preview locally
1. Extract the ZIP file.
2. Open the `yeshambel_academic_website` folder.
3. Double-click `index.html` to preview it in a modern browser.
4. For development, you may use Visual Studio Code and the Live Server extension (optional).

The page uses Google Fonts from the internet. The website otherwise has no build step or package dependencies.

## Publish for free with GitHub Pages
1. Sign in or create an account at https://github.com/.
2. Create a new public repository. A good name is `yeshambel-academic-portfolio`.
3. Upload all files in this folder, including the CV document and professional photograph, to the repository root (not inside an extra nested folder).
4. Open the repository's **Settings** → **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then click **Save**.
7. Wait for the deployment to complete. The published address will be similar to:
   `https://YOUR-GITHUB-USERNAME.github.io/yeshambel-academic-portfolio/`
   Replace `YOUR-GITHUB-USERNAME` with your actual GitHub username. GitHub will show the exact URL in Settings → Pages.

For a personal site at `https://YOUR-GITHUB-USERNAME.github.io/`, name the repository exactly `YOUR-GITHUB-USERNAME.github.io`.

## Customize before publishing
- Replace any wording in `index.html` that you want to change.
- Add a real profile photograph if desired: put it in `assets/`, then update the hero card in `index.html`.
- Verify the article details and Google Scholar URL before publishing.
- A downloadable academic CV is included as `Yeshambel_Asmare_Academic_CV.docx`.
- ORCID profile is included: https://orcid.org/0009-0000-8782-4157. Verify that your ORCID record is public and up to date.
- Check the website on both a phone and a desktop browser.

## Important notes
- The contact email link opens the visitor's email app; this static website does not include a backend contact form.
- Do not add private phone numbers or personal details unless you intentionally want them public.
- The author line for the featured article is abbreviated in the page; update it to the publisher's exact author list if you prefer a full citation.
